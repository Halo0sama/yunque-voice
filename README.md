# 云雀·私人助理（yunque-voice）

一款 Android 端全天候语音私人助理：持续聆听、自主判断是否开口、有记忆、认识你身边的人。

## 核心特性

- **全天候聆听**：前台服务 + 16kHz 采集，能量 VAD 自适应切分（噪声地板自动跟踪）
- **旁听决策**：每句话由对话模型判断"此刻该不该说话"，克制不抢话；随时可被"云雀请发言"强制发言
- **三层记忆**：
  - 工作记忆（本地）：48h 原话窗口 + 滚动摘要，重启零失忆
  - 画像文档（本地）：AI 每晚维护的"你是什么样的人"，预算自适应，可编辑
  - 云端记忆库（阿里云百炼）：夜间压缩产出事实，语义检索注入
- **说话人分离**：批内云端 DIAR 权威分簇，跨批本地声纹锚定身份
- **对话面板**：文字聊天与语音共用同一条对话流与记忆
- **仅聆听两档**：完全沉默（零消耗）/ 文字回应（写面板不播报）
- **对话模型可切换**：DeepSeek / 智谱 GLM / 阿里 Qwen 一键切换（各家思考模式差异化适配）
- **音频路由**：输入输出设备按系统原始名选择（手机麦+耳机出声可保 A2DP 音质）
- **本地 CLI/MCP**：127.0.0.1:8766，REST + JSON-RPC 工具
- **每日数据导出**：原始数据自动打包，供离线分析与自进化闭环

## 隐私

对话、声纹、画像等数据全部保存在手机本地；长期记忆可选存放于你自己的阿里云百炼记忆库。APK 不含任何个人数据。

## 构建

```bash
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

需要自行配置：对话模型 API Key、阿里云百炼 Key/业务空间/记忆库 ID（App 设置页内填写）。
